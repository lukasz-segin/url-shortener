# URL shortener

Simple API for shorten and retrieve original URL from a shortened URL

## Getting Started

### Installing

* Create venv with
```
source .venv/bin/activate
```

### Executing program

* Run app with
```
python manage.py runserver
```
* Go to browser and execute example URL
```
http://127.0.0.1:8000/short/?url=https://example.com/very-very/long/url/even-longer
```
